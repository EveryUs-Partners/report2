# 편의점 근무기록 웹앱

편의점 2곳 직원의 출퇴근(근무시간)을 기록하고, 위치(GPS)로 매장 도착을 검증하는 웹앱입니다.
Netlify에 그대로 배포되며, 별도 DB 가입이 필요 없습니다(Netlify Functions + Netlify Blobs 사용).

## 기능

| 구분 | 기능 |
|---|---|
| 직원 모드 | 이름+PIN 로그인 · 매장 선택 후 출근/퇴근 버튼(GPS 위치 확인) · 월별 내 기록·합계 · 출퇴근 누락 시 수기 입력(관리자 확인 대기) · PIN 변경 |
| 관리자 모드 | 월별 전체 근무기록(직원/매장 필터) · 출퇴근 시 매장과의 거리 확인 · 기록 추가/수정/삭제 · 수기 입력 확정 · 직원×매장별 월 집계 · 직원 등록/PIN 재설정/퇴사 처리 · 매장 위치·반경 설정 · CSV 내보내기(엑셀 호환) |
| 위치 검증 | 서버에서 매장 좌표와의 거리를 계산. 반경(기본 100m) 밖이면 출퇴근 차단(관리자가 해제 가능) |
| 보안 | 관리자 비밀번호는 환경변수, 직원 PIN은 해시 저장, 5회 오입력 시 10분 잠금, 서명 토큰 |

## 배포 방법 (Netlify)

1. GitHub에 이 저장소를 올리고 Netlify → **Add new site → Import an existing project** 로 연결합니다.
   (빌드 설정은 `netlify.toml`에 있어 그대로 두면 됩니다. Publish directory: `public`)
2. **Site configuration → Environment variables** 에서 아래를 추가합니다.
   - `ADMIN_PASSWORD` : 관리자 로그인 비밀번호 (필수, 추측하기 어려운 값)
   - `SESSION_SECRET` : 로그인 토큰 서명용 임의 문자열 (선택, 권장)
3. 배포 후 사이트 주소(https)에 접속합니다. **GPS는 https에서만 동작**하며 Netlify는 기본 https입니다.

> ※ Netlify에 직접 폴더를 드래그 앤 드롭하는 방식은 Functions/Blobs가 동작하지 않을 수 있습니다. Git 연동 또는 `netlify deploy` (CLI) 를 사용하세요.

## 최초 설정 (관리자, 약 5분)

1. 사이트 접속 → **관리자 모드** 로그인
2. **직원** 탭: 직원 이름과 PIN(숫자 4~6자리) 등록
3. **매장** 탭: 각 매장에 **직접 방문한 상태**의 휴대폰으로 접속해 「📍 현재 위치로 설정」 → 저장
   (매장명은 실제 이름으로 변경, 반경은 실내 GPS 오차를 감안해 100~150m 권장)
4. 직원들에게 사이트 주소와 PIN을 안내 (휴대폰 홈 화면에 바로가기 추가 권장)

## 로컬 테스트

```bash
npm install
npm test                 # API 스모크 테스트 (위치 차단·야간근무·권한·잠금 등)
npx netlify-cli dev      # 로컬 실행 (ADMIN_PASSWORD 환경변수 필요)
```

## 알아둘 한계 (운영 전 확인)

- **GPS 위조**: 휴대폰 위치는 앱/브라우저 단에서 조작될 수 있어 100% 방지는 불가능합니다. 관리자 화면의 거리 기록으로 사후 확인하는 용도로 쓰세요.
- **실내 오차**: 지하/건물 안에서는 오차가 클 수 있습니다. 오차 300m 초과 시 재시도를 안내하며, 반경이 너무 좁으면 정상 출근도 막힐 수 있습니다.
- **직원 이름 노출**: 로그인 화면에 재직 직원 이름 목록이 보입니다(주소를 아는 사람 누구나). 민감하면 배포 주소를 직원에게만 공유하세요.
- **급여 계산 아님**: 근무시간 기록·집계용입니다. 주휴수당·야간가산 등 급여 계산은 CSV를 내려받아 별도 처리하세요.
- **저장소**: Netlify Blobs 사용량은 소규모(직원 10명 내외) 기준으로 무료 범위 안입니다.
